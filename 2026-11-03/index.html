agent-desktop swaps screenshots for the accessibility tree

Vercel Labs' Rust CLI gives agents deterministic computer use.

Read the briefing +

Vercel Labs open-sourced agent-desktop, a Rust CLI and C library that lets AI agents read and operate desktop apps through the OS accessibility tree, the same data screen readers use, instead of guessing from screenshots.

  • The loop: Snapshot an app to JSON with refs for every actionable element, act on a ref, then re-snapshot to verify; Apache-2.0, on macOS, Windows and Linux.
  • The signal: It topped GitHub Trending on November 2 with roughly 7.7K stars, adding over 2,200 in a day; latest release v1.0.2 is dated October 30.

FBI: North Korea took $6.43 billion from Binance

The largest crypto theft in history gets an official attribution.

Read the briefing +

The FBI has officially attributed the theft of more than $6 billion in virtual assets from Binance to North Korean hacking group TraderTraitor, per The Hacker News.

  • The haul: $6.43 billion across 11 blockchains, 82% of it on Ethereum and Bitcoin, eclipsing the $1.46 billion Bybit theft of February 2025.
  • The clawback: $2.85 billion has been frozen on-chain by Tether, Circle, Ripple, Arbitrum and Optimism.

Barracuda patches two flaws that chain to root

A 9.3 authorization bypass on Email Security Gateway, plus command injection across six products.

Read the briefing +

Barracuda patched a pre-authentication authorization bypass (CVE-2026-116606, CVSS 9.3) on its Email Security Gateway and a command injection (CVE-2026-111560, CVSS 8.6) across ESG, Load Balancer ADC, Message Archiver, WAF, WAF Control Center and Web Security Gateway.

  • The risk: Chained on ESG, the pair can give an attacker with admin-interface access root.
  • Vendor guidance: Keep admin interfaces off the internet, per Barracuda's advisory and today's SANS Stormcast.

Starship makes orbit, then comes home early

Flight 14 deployed 26 next-gen Starlinks before an early engine shutdown cut the mission short.

Read the briefing +

SpaceX's Starship reached orbit for the first time on Monday, its 14th full-scale flight, and deployed 26 of the most advanced Starlink satellites yet.

  • The drama: One engine shut down early; controllers proceeded, then ended the flight after about three hours instead of a planned ten, splashing down north of Hawaii, where the ship tipped over and caught fire. SpaceX called it an abundance of caution.
  • What's next: NASA Administrator Jared Isaacman publicly congratulated SpaceX; depending on the findings, the next ship may attempt a return to the pad for a catch. Reported by the AP.
