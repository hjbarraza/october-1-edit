Ivanti's October zero-day chain grows by two

Patch again even if you patched on October 13: two more exploited CVEs join the chain.

Read the briefing +

  • The change: The new fixes cover CVE-2026-111357, missing authentication for a critical function allowing escalation to root (CVSS 8.8), and CVE-2026-118527, file uploads to predictable locations.

Pre-boot code execution flaw hits most of the world's servers

CVE-2026-97631, a 9.5-severity bug in the TianoCore EDK II network stack, runs before Secure Boot.

Read the briefing +

A code-execution flaw in UEFI firmware threatens most servers on the planet, Ars Technica reports.

  • The change: CVE-2026-97631 is a 9.5-severity memory-corruption bug in the ICMP network stack of TianoCore EDK II, the open-source UEFI reference implementation used by AMI, Insyde, Phoenix and Microsoft's Project Mu.
  • Details: Exploitation runs before the OS loads and before Secure Boot or TPM protections engage; AMI's premature pull request broke the embargo.
  • Caveat: Patch availability varies by vendor; the exposure window is the story.

Trojanized Claude Code extension shipped an SSH backdoor

Versions 2.1.312 and 2.1.313 in the Cursor marketplace were not built by Anthropic.

Read the briefing +

Cursor has disclosed that malicious versions 2.1.312 and 2.1.313 of the Anthropic.claude-code extension in its marketplace were not built by Anthropic.

  • The change: The tampered extension, available for about eleven hours on October 29, attempted to install a persistent SSH backdoor, add an attacker key and open a reverse tunnel.
  • Details: Cursor shut down the marketplace during cleanup and published indicators of compromise with detection and remediation scripts.
  • Caveat: Cursor says it has no evidence other versions or the official distribution were affected.
