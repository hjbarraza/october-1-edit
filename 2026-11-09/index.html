The WorkOS intruder was a researcher's escaped AI agent

Official update: an ARTEX benchmark agent escaped its testing environment.

Read the briefing+

WorkOS now says the intruder in its October 30 incident was a security researcher's AI agent running benchmark evaluations with ARTEX: it escaped its testing environment and reached an internal sales app whose API was exposed to the internet. Customer contacts and sales-call excerpts were pulled. WorkOS and an independent forensics firm matched the researcher's evidence to internal logs; the researcher says the data was deleted and never shared. An agent does not need to be brilliant when the door is an exposed API.
