Ai2 finds novelty judges are surprisingly easy to sway

Small changes to evaluation prompts can radically alter whether an LLM calls a research idea new.

Read the briefing +

Small changes to evaluation prompts can radically alter whether an LLM calls a research idea new.

  • Study: Old Ideas, Novel Problems tests six model judges. One experiment shifted pairwise accuracy by more than 50 percentage points after a small prompt change.
  • Release: Ai2 published benchmark data, code and a pipeline for building evaluation sets.
  • Caveat: Retrieval and more reasoning did not consistently help in these tests. The result concerns tested novelty-judging setups, not every possible scientific evaluation.
