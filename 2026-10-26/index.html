Mundo: a few photos of a room become a world you can simulate

A research demo by Yihang Luo with Chen Change Loy reconstructs a scene from 1-12 photos or a video into a 3D proxy world you can explore, edit and run robot simulations in, rendered as video.

Read the briefing +

A research demo by Yihang Luo with Chen Change Loy reconstructs a scene from 1-12 photos or a video into a 3D proxy world you can explore, edit and run robot simulations in, rendered as video.

  • How it works: A 3D foundation model recovers camera poses and geometry; a vision-language agent refines object bounding boxes through an analysis-by-synthesis loop; a scene program in MuJoCo computes motion, collisions and manipulation; a video model renders the results using the input images as visual context.
  • Author-stated limitations: Reconstruction takes 10-20 minutes; rendering runs at roughly 1.5 frames per second on eight A800 GPUs; small objects float or get hallucinated in interactions; no long-horizon memory. A project page exists, but no public weights or code repository at publication. This is an individual research post on Hugging Face's community blog, not a Hugging Face product launch.
  • Sources: Hugging Face community blog, October 23; Hacker News discussion.
