Read the briefing +

PwnEscape is a 9.3-rated Linux KVM flaw that can let a guest reach the host with malformed IPv4 packets.

  • Risk: Red Hat says impact can include host code execution, a crash or sensitive-memory disclosure, crossing the core cloud-isolation boundary.
  • Mechanism: Guest-controlled checksum metadata can alter a packet after earlier validation, which the researcher argues may be a new Linux networking attack class.

The world votes to stop leap seconds

The ITU has agreed to end leap seconds by 2035, removing one of computing's strangest recurring hazards.

Read the briefing +

The ITU has agreed to end leap seconds by 2035, removing one of computing's strangest recurring hazards.

  • History: Twenty-seven leap seconds have been inserted since 1972, but only four this century as Earth's rotation has run faster.
  • Problem: A negative leap second may have been next, and no large-scale system has ever had to process one.
  • Afterlife: UTC and atomic time will drift apart by about two minutes by 2135; GNSS and networks already handle time through other scales and smearing.
