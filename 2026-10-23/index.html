OpenAI turns small decisions into a general API

The GPT-6 Luna-backed service answers bounded questions at agent speed.

Read the briefing +

OpenAI is carving the tiny judgments inside agents into a product of their own.

  • What happened: OpenAI made the Decisions API generally available on October 22 for questions with bounded answers.
  • Details: The API uses GPT-6 Luna, accepts text, images and native JSON, and can answer up to 400 questions per request. OpenAI says it can run up to 10 times faster than GPT-6 Luna through the Responses API.
  • Why it matters: The product is aimed at routing, scoring, risk checks and live voice agents. Box, Datadog, Ramp, Sierra and Speak supplied customer examples.
  • Caveat: The speed and cost figures are vendor and customer examples for narrow tasks. Decisions is not positioned as a replacement for open-ended reasoning.

Kevin Weil’s new lab wants robots and AI to close the loop in drug chemistry.

A high-profile AI team is moving from software into the physical bottleneck of drug discovery.

Microsoft claims a benchmark win for medical diagnosis

Its Diagnostic Orchestrator beat physicians on past cases, with hospital tests next.

Read the briefing +

Microsoft is putting numbers behind its medical superintelligence ambition, while keeping the clinical caveat in view.

  • What happened: Microsoft published results for MAI-DxO, an AI system that coordinates multiple agents through step-by-step diagnosis.
  • Details: On hundreds of New England Journal of Medicine case reports, Microsoft reports about 83 percent accuracy versus roughly 36 percent for physicians with references and 22 percent without. On emergency-department cases drawn from a Beth Israel Deaconess Medical Center database, it reports 80 percent versus 47 percent.
  • Why it matters: Microsoft compiled the cases into its SDBench benchmark, which it plans to open-source.
  • Caveat: The results come from historical cases and company-run evaluations. Microsoft says clinical validation is still needed and has not committed to a commercial launch date.

Hugging Face releases Carbon-X, an open model that chats with DNA

The 14.8B-parameter model runs locally and answers in English about genetic sequences.

Read the briefing +

Hugging Face is turning genomic sequences into something researchers can interrogate conversationally.

  • What happened: Hugging Face released Carbon-X, an open 14.8B-parameter model trained jointly on DNA sequences and natural language.
  • Details: It uses a hybrid tokenizer for text and six-base-pair DNA tokens, has a 40,960-token context window, and can run on one GPU. The model averages 66.7 percent across five DNA benchmarks in the developers’ evaluation.
  • Why it matters: Researchers can ask whether mutations look benign or pathogenic and inspect small genome segments without sending sensitive data to a cloud model.
  • Caveat: The developers have not validated predictions in wet-lab experiments. The model handles roughly 50,000 base pairs at a time.

OlmoEarth v1.3 turns the planet into reusable embeddings

AI2 is releasing global 10-meter satellite embeddings and a browser map anyone can query.

Read the briefing +

AI2 is making satellite analysis cheaper by computing the hard representation layer once and sharing it openly.

  • What happened: AI2 released OlmoEarth v1.3, annual global embeddings at 10-meter resolution, and a browser-based Embeddings Explorer.
  • Details: The model reads Sentinel-1, Sentinel-2 and Landsat time series and produces 64- or 128-dimensional vectors for each land pixel. AI2 says the 128-dimensional embeddings lead on 20 of 27 evaluations.
  • Why it matters: The archive lets users test mapping ideas in seconds without a GPU. Weights, data and code are open, and AI2 estimates the final pre-training run cost about $2,720 in rented H100 time.
  • Caveat: The benchmark ranking is AI2’s own evaluation. Global annual embeddings launch for 2023 through 2025, while 2017 to 2022 coverage is still selective.

New open embed, rerank and parse models target evidence-heavy agent workflows.

Read the briefing +

Nvidia is treating retrieval quality as an agent-cost problem, not only a search-quality problem.

Google open-sources its Elephant-Goldfish coding workflow

The plugin separates long-horizon design memory from stateless adversarial review.

Read the briefing +

Google’s answer to AI coding slop is to split the model’s memory from its critic.

  • What happened: Google open-sourced the Elephant-Goldfish Model plugin, originally built for internal software engineers.
  • Details: The Elephant is a long-running design session that keeps context and writes no code. Stateless Goldfish sessions then test the spec through comprehension checks, hostile review and a go/no-go readiness check.
  • Why it matters: The workflow tries to preserve architectural intent while using fresh sessions to catch ambiguity before implementation. Google says thousands of employees use the plugin, now in Antigravity with more environments planned.
  • Caveat: This is a process tool, not proof that generated code is correct. It still depends on a useful design document and human judgment.

Microsoft turns database checks into training rewards for agents

ThinkingBox-Training grades what an agent actually changed, then uses that signal for RL.

Read the briefing +

Microsoft is closing the gap between an agent saying it is done and the database agreeing.

  • What happened: Microsoft released ThinkingBox-Training on GitHub, extending its ThinkingBox agent-evaluation work into post-training.
  • Details: ThinkingBox-Bench has 507 tasks that compare the final database state with the expected outcome. Using executable checks as GRPO rewards, Qwen3.8-27B's average task success rose from 51.70 to 60.78 percent, and tasks completed correctly in all 20 attempts rose from 38 to 107.
  • Why it matters: A database diff is a verifiable 1-or-0 signal: it catches agents that declare victory early, and the same check doubles as a reward function without a learned judge.
  • Caveat: Results cover one model and one task family, and the training tasks share a format with the benchmark, which limits the transfer claim.

Microsoft says AI agents industrialized the ConnectWise breach fallout

Storm-0940 used stolen app credentials and ARTEX to hit downstream Microsoft 365 tenants.

Read the briefing +

The ConnectWise breach shows how agentic automation changes the tempo of supply-chain attacks.

  • What happened: Microsoft says China-aligned Storm-0940 used compromised ConnectWise cloud application credentials and the open-source ARTEX agent framework to authenticate into downstream customer environments.
  • Details: In one campaign subset, Microsoft recorded more than 2,250 tenants reached, 327 accounts across eight organizations, and peaks above 2,900 sign-in attempts per minute.
  • Why it matters: The attacker did not need interactive user sign-ins because abused applications already had trusted access. Microsoft warns that modified app credentials can persist as backdoors.
  • Caveat: Microsoft says tenant reach or successful authentication does not prove customer data was accessed or exfiltrated. ConnectWise paused the affected cloud backup service while investigating.

Hijacked Tor exits intercepted SSH and plaintext email

A researcher says 333 relays were pulled into a three-day interception campaign.

Read the briefing +

Tor’s encrypted web traffic kept moving, but SSH and email were steered into a trap.

  • What happened: Unknown attackers compromised a Tor management server and ultimately involved 333 exit relays in an interception campaign, according to a Tor volunteer report covered by Ars Technica.
  • Details: The relays redirected SSH connections through attacker-controlled servers and blocked encrypted email ports while allowing unencrypted alternatives. The attackers used the Ebury Linux backdoor.
  • Why it matters: Users who ignored SSH host-key warnings could have passwords stolen, sessions watched and servers infected. Email systems that downgraded to plaintext were exposed.
  • Caveat: Investigators still do not know how every server was compromised or who ran the campaign. Encrypted web traffic was not the reported target.

Nvidia simulates a cheaper route to fault-tolerant quantum

The 104-qubit JUPITER run points to 90 percent fewer physical qubits, on classical hardware only.

Read the briefing +

Nvidia is using GPUs to test quantum error-correction designs before the hardware exists.

  • What happened: Nvidia researchers simulated a 104-qubit fault-tolerant quantum system on the JUPITER supercomputer at Germany’s Jülich Supercomputing Centre.
  • Details: The run used 8,192 GPUs, cuQuantum and CUDA-Q to study magic state cultivation under realistic noise. Nvidia says the approach could cut physical qubit requirements by 90 percent.
  • Why it matters: Large classical simulations let researchers compare quantum processor designs before building expensive hardware.
  • Caveat: This was a simulation, not a demonstration on a real quantum processor. The 90 percent saving still needs experimental validation.
