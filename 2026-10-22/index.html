Claude Duet is Anthropic’s bid to make Claude an always-on work agent

The research-preview app moves beyond chat into scheduling, monitoring, research and small app building.

Read the briefing +

Anthropic is testing a Claude product designed to sit on top of work, not just answer questions.

  • What happened: Claude Duet is available as a research preview on iOS, Android and the web, with a standalone interface built around Claude Opus 5.5.
  • Details: The app can prepare morning briefings, watch connected apps and documents, manage calendars, create dashboards and forecasts, research topics and build simple web apps or prototypes.
  • Why it matters: Anthropic says Duet uses Claude memory, skills and connected applications, can browse in a dedicated virtual machine, and asks for approval before sensitive actions such as purchases or deletions.
  • Caveat: It is US-only and waitlisted for Pro and Max subscribers. Anthropic says Duet can misread conversational context, misunderstand urgency and perform personal errands less reliably.

The Apache-licensed model is designed to run privately on a laptop.

  • Caveat: The benchmark and speed figures are company-reported. Recursive’s longer-term recursive self-improvement goal remains a research direction, not an achieved result.

Omnara pitches an open-source control plane for managed agents

The project offers durable agents, sandboxes, secrets and permissions outside the major labs.

Read the briefing +

Omnara wants teams to run Claude Code-style managed agents without locking the control plane to one model provider.

  • What happened: The project describes itself as an open-source alternative to Claude Managed Agents and the OpenAI Agents API, with durable agents, isolated sandboxes, secrets and integrations.
  • Details: Agents keep state in Postgres, are driven through an event log and can be resumed across workers after failures.
  • Why it matters: A lightweight daemon can connect laptops, home labs or cloud machines as agent workers, while the control plane handles authentication, RBAC and audit trails.
  • Caveat: This is an early self-hosted project. Its repository and documentation describe the design, but self-hosting shifts patching, sandbox isolation and credential security onto the operator.

Alter adds access control for multi-user AI agents

The YC-backed layer gives agents scoped identities, approvals, audits and memory boundaries.

Read the briefing +

Alter is targeting the gap between a shared agent and the individual permissions of the people using it.

  • What happened: Alter proxies agent API calls and gives each agent identity, scoped grants and credential injection without exposing raw secrets to the model.
  • Details: Policies can enforce read-only access, scoped writes, rate limits, human approval for risky operations, revocation and audit trails.
  • Why it matters: The system partitions memory by end user and agent, aiming to prevent one user’s shared-agent memory from leaking into another user’s context.
  • Caveat: The claims come from the company’s launch materials and Hacker News discussion. The site says SOC 2 Type II is in progress, so the control should not be treated as independently certified yet.

LiteLLM 1.107.0 on PyPI carried a credential-stealing backdoor

SafeDep says the poisoned package could execute on Python startup even without an import.

Read the briefing +

A popular AI gateway package became a supply-chain risk after a compromised PyPI release.

  • What happened: SafeDep reported that all seven LiteLLM 1.107.0 wheel distributions on PyPI contained malicious code in site-packages initialization files.
  • Details: The code could run at Python startup, steal SSH keys, cloud and CI/CD credentials, browser passwords, LLM proxy keys and tokens, then install an hourly remote-access mechanism.
  • Why it matters: SafeDep found no malicious code in the corresponding GitHub tag, while 1.106.2 and the 1.107 release candidates were clean. PyPI removed the compromised release.
  • Caveat: Users need to check the exact installed version and treat exposed credentials as compromised. The report did not establish attribution or a final installation count.

CISA warns SafePay ransomware has hit roughly 600 victims in 2026

The advisory details credential abuse, VPN weaknesses, backup deletion and double extortion.

Read the briefing +

SafePay is scaling fast enough that five governments are telling defenders to harden identity and backups now.

  • What happened: CISA, the FBI, the US Secret Service and international partners say SafePay has claimed about 600 victims across the Americas, Europe and Australia this year.
  • Details: The group gains access through compromised credentials or known vulnerabilities in internet-facing devices and VPN concentrators, then uses legitimate tools to move and steal data.
  • Why it matters: SafePay deletes backups, encrypts files, leaves a README ransom note and sometimes calls victims to increase pressure.
  • Caveat: The advisory is defensive guidance rather than a named-victim disclosure. It does not attribute the group to a state or give a confirmed total of successful ransom payments.
